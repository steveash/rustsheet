## Goal
T-2134 gets a dense set of excel-graph SINH, TANH and COSH values on (-1, 1), enough to fit (or rule out) a
formulation of Excel's hyperbolic kernel there instead of guessing from the few hundred cached points.

## Context
- T-2134 (M5, functions-math, opus) fits Excel's SINH/TANH kernel on |x| < 1; COTH, CSCH and SECH are 1 over
  them (T-0917), so the same fit settles them. Its own Context says "A dense oracle sweep on (0, 1) is likely
  needed": T-0917 rejected every simple formulation (docs/excel-semantics/numbers.md "SINH and TANH on 0.4 .. 1:
  no formula found yet") against the points cached today, which are sparse:
  probes-numeric `m9-hyperbolic` A157-A248 and `t0917-hyperbolic-switchover` A79-A210 (T-1005 sweep), plus
  ironcalc-calc `MATH_AND_TRIGONOMETRY/TRIGONOMETRIC.xlsx` SINH_COSH_TANH.
- Current misses on (-1, 1), all 1 ulp (excel-graph): 26 SINH, 18 TANH, 2 COTH, 2 CSCH cells of `m9-hyperbolic`;
  13 SINH, 12 TANH, 11 CSCH, 10 COTH cells of `t0917-hyperbolic-switchover`; 19 gen-m5 cells (listed in T-2134);
  probes-numeric `power-ulp-sources` Calc!A4, A5, A6, A7, A11, A12 (`TANH(0.4)` Excel 0.3799489622552249, ours
  0.37994896225522484); gen-m6/ed0f4f783473cef0 Calc!A23 (`TANH(SUM(..))` Excel 0.3798633951257878, ours ...879).
  Examples: `SINH(0.3)` 0.3045202934471426 (ours ...254), `SINH(PI()/4)` 0.8686709614860096 (ours ...095).
- Engine code the fit will change: `crates/rustsheet-engine/src/functions/math_and_trigonometry/hyperbolic.rs` (`sinh`, `sinh_series`;
  T-0914's exp formulas), x87 EXP model V6 in `crates/rustsheet-engine/src/x87_exp.rs`.
- Fit lab: docs/research/excel-kernel-playbook.md (T-1523). Case format: as T-2143's
  `t2143-ln-near-ties` (stored inputs in column A, formulas reading them), `excel-probe` skill.

## Acceptance criteria
- [ ] A new probes-numeric case `eval/suites/probes-numeric/cases/t2178-hyperbolic-unit-sweep.case.json`
      (`rustsheet-case/v1`, sheet `Calc`) stores each x in column A and has `=SINH(A<n>)`, `=TANH(A<n>)` and
      `=COSH(A<n>)` in B, C, D. The x set, generated by a short seeded script (not typed by hand) and recorded in
      the case description:
      - the short decimals k/500 for k = 1 .. 499 (gen-m5's inputs are of this kind: 0.3, 0.2, 0.41);
      - 300 seeded uniform random doubles in (0, 1);
      - 100 log-spaced x in [1E-8, 1E-2];
      - every argument of the misses listed above that is not already in the set (PI()/4 stored as its double);
      - the negatives of 100 of the above (odd symmetry), and 20 points in (1, 1.5) as a control past the range.
- [ ] Its excel-graph sidecar is filled with
      `cd tools && uv run rustsheet-oracle fill -b excel-graph --suite probes-numeric`; no pending cells.
- [ ] numbers.md "SINH and TANH on 0.4 .. 1: no formula found yet" links the case and states how many cells the
      current engine matches (from `make eval-show CASE=probes-numeric/t2178-hyperbolic-unit-sweep.case.json`).

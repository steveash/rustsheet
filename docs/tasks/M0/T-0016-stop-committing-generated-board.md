## Goal
PRs no longer conflict on `docs/tasks/BOARD.md`.

## Context
On 2026-10-04 most merged PRs (#44, #46, and the PR that filed this task) hit a BOARD.md conflict because the
generated file is committed and every task change rewrites its counts. Each conflict costs a
merge, a regenerate, a `make check` and a CI cycle.

## Acceptance criteria
- [x] Either BOARD.md is no longer committed (generated by `make board`, git-ignored, rendered in CI or by the steward) or a `.gitattributes` merge driver regenerates it; pick one and record why.
- [x] Docs and skills that say "run `make board`" match the choice; no gate weakens (`tasks.py validate` still runs in CI).
- [x] Decision record for the protected-path change; `make check` green; reviewers approve.

## Out of scope
Changing the task file format.

## Outcome
Chose "not committed": a merge driver cannot help because GitHub computes mergeability without it.
BOARD.md is git-ignored and removed; `make board` writes it locally; docs, skills and CLAUDE.md
updated. Decision 0017. Eval delta: none.

## Goal
PRs no longer conflict on `docs/tasks/BOARD.md`.

## Context
On 2026-10-04 most merged PRs (#44, #46, and the PR that filed this task) hit a BOARD.md conflict because the
generated file is committed and every task change rewrites its counts. Each conflict costs a
merge, a regenerate, a `make check` and a CI cycle.

## Acceptance criteria
- [ ] Either BOARD.md is no longer committed (generated by `make board`, git-ignored, rendered in CI or by the steward) or a `.gitattributes` merge driver regenerates it; pick one and record why.
- [ ] Docs and skills that say "run `make board`" match the choice; no gate weakens (`tasks.py validate` still runs in CI).
- [ ] Decision record for the protected-path change; `make check` green; reviewers approve.

## Out of scope
Changing the task file format.

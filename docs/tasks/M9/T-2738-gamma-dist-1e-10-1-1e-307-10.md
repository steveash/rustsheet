## Goal
GAMMA.DIST returns Excel's #NUM! where its scale is near the top of the double range, at the bound Excel uses.

## Context
`GAMMA.DIST(1E-10,1,1E+307*10,FALSE)` is #NUM! in Excel (probes/t2706-subnormal-density-paths A25:B25, excel-graph
2026-10-25) while the engine returns 0 through statrs' density (gamma.rs `gamma_dist_of`; `gamma_density` is `None`
because x / scale is not normal). The true density is 1E-308, so it is not an overflow of the result. Probe first
(excel-probe skill): the scale (1E+307, 1E+306, 1E+300), the shape (1, 2, 0.5), x (1, 1E+300), the cumulative mode, and
GAMMADIST and CHISQ.DIST through the same path, then record the bound in statistics.md and match it.

## Acceptance criteria
- [x] A probes case brackets the #NUM! bound; statistics.md records it.
- [x] The engine matches it; probes/t2706-subnormal-density-paths A25:B25 pass.
- [x] `make check` green; reviewers approve.

## Out of scope

## Outcome
probes/t2738-gamma-dist-tiny-ratio (20 calls with companions) shows the bound is x / beta, not the scale: the density
is #NUM! exactly when x / beta is subnormal (4.4E-308 / 2 is #NUM!, 4.5E-308 / 2 a number), at any shape and for
GAMMADIST; the cdf there is 0. gamma.rs returns #NUM! there (test/statistical/test_subnormal_results.rs); recorded in
statistics.md. Excel's density near the bound is 1E-14 relative off the exact one: T-2753.

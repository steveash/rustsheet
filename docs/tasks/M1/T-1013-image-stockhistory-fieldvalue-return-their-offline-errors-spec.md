## Goal
IMAGE, STOCKHISTORY and FIELDVALUE evaluate to Excel's offline errors (`#BLOCKED!`, `#CONNECT!`, `#FIELD!`) instead of `#NAME?`, with no I/O.

## Context
SPEC-0003 "Functions with no I/O" (rollout F1). Known failures: probes/rich-errors-image (5 cells), -stockhistory (4) and -field (4). Argument-error precedence comes from T-1012's probe.

## Acceptance criteria
- [x] The three functions are registered with Excel's arity (including the `_xlfn.` prefix). They return the spec's error after argument errors as T-1012 found, never spill, and do no I/O.
- [x] information.md entries for IMAGE and STOCKHISTORY have `Status: DEVIATION (decision 0014)`: reachable URLs and real tickers give errors, where Excel fetches. FIELDVALUE's entry is VERIFIED.
- [x] COUNTIF-family criteria naming the new errors follow T-1012's evidence. `is_english_error_string` changes only if Excel matches the error, and the test cites the probe cell.
- [x] The 13 rich-errors-* known failures pass and are recorded with `make eval-baseline`, with no regressions.
- [x] `make check` green; reviewers approve.

## Out of scope
- Linked data types, image values, and stock data (decision 0027).

## Outcome
- IMAGE, STOCKHISTORY and FIELDVALUE are registered, with `_xlfn.` names and arity, in functions/information/offline_errors.rs. They return `#BLOCKED!`, `#CONNECT!` and `#FIELD!` after T-1012's argument-error precedence, and do no I/O. Names are in the language tables and `language.bin` was regenerated.
- A range argument is read through its top-left cell only.
- information.md: IMAGE and STOCKHISTORY are a DEVIATION entry (decision 0014); FIELDVALUE is VERIFIED.
- COUNTIF criteria and `is_english_error_string` are unchanged, as T-1012's evidence requires: a `"#BLOCKED!"` criterion does not match the error (information.md, "IS*, TYPE, IFNA and COUNTIF on the newer rich errors").
- Handed off from sonnet to opus (tier changed then) because only the file-size ratchet blocked it. The fix: `Function::into_iter` is now generated by `impl_function_lookup!` from the lookup table instead of a hand-kept 500-line list. That takes functions/mod.rs from 2874 to 2388 lines, recorded via `check_file_size.py --update` (decision 0010).
- Eval delta: probes known failures −37 (the 13 rich-errors-image/-stockhistory/-field cells and 24 rich-errors-args cells), 0 regressions in every suite.
